# RoshanOS

**Giving direction to life.**

A personal operating system — journal, planner, habits, challenges, learning, trading, and reflection, all in one quiet, offline-first app.

## Features
- Daily journal with 30+ guided prompts
- Weekly planner with recurring templates
- Reminders with due dates and recurring auto-renewal
- Habit tracker with streaks and weekly grid
- 30-day challenges with Do/Don't rules
- Learning notebook with categories, tags, and daily words
- Trading journal with NEPSE fee calculator
- Weekly review
- Archive with search and mood filters

## How to use
Open `index.html` locally, or visit [your URL].

## Install
Add to home screen from your browser menu — it works offline.

## Storage
All data lives in your browser's localStorage. Use Settings → Export backup regularly.
